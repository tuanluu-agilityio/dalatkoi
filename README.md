# Dalat Serenity

*Somewhere between the forest and the silence.*

An explorable 3D mountain retreat in the pine forest of Đà Lạt, Vietnam: a wooden cabin with a
lantern-lit veranda, a koi pond fed by a bamboo spout, an arched footbridge, hydrangeas, and
morning mist under tall three-needle pines. It runs in the browser as a single page. Walk through
it, take the guided tour, or look over the clearing from above.

**Live:** https://dalatkoi.netlify.app

Everything is drawn live. The geometry and all sound are generated by the code in this repository.

## Run it

Requires Node 20 or newer.

```bash
npm install
npm run dev        # http://localhost:5173
```

If another dev server already uses port 5173 on `localhost`, open `http://127.0.0.1:5173/`.

```bash
npm test           # 117 unit tests
npm run typecheck
npm run build      # type-check, then production build in dist/
npm run preview    # serve the production build
npm run fetch-textures   # re-download the CC0 textures (already committed in public/textures)
```

The build uses relative paths (`base: './'`), so `dist/` can be hosted in any folder of a static
host.

## Controls

| | Desktop | Touch |
|---|---|---|
| Walk | `W A S D` or arrows, `Shift` to jog | Left thumb pad; push to the rim to jog |
| Look | Click the scene, then move the mouse (`Esc` releases). Click-drag also works | Drag anywhere |
| Zoom lens / orbit distance | Scroll | Pinch (Orbit) |
| Read the note where you stand | `E` | Tap the note |
| Camera mode | `1` Walk · `2` Tour · `3` Orbit, or the switcher | The switcher |
| Weather | `R` switches Morning / Rain; the switch (top right) also sets Drizzle, Moderate or Heavy | The switch under the camera modes |
| Sound | `M` mutes; the speaker button opens the mixer | Speaker button |
| Other | `F` full screen · `H` help · `P` frame-rate readout | Buttons |

The interface fades out after four seconds without input and returns on any mouse movement or tap.

## What is in it

- **World:** terrain with a carved pond bowl and gravel paths, three mountain ridges in haze, a
  timber cabin with clay-tile roof, stone plinth and chimney, veranda with furniture, lanterns and
  a wind chime, an arched bridge, flagstones, a bamboo spout.
- **Water:** planar reflection, depth-tinted see-through body, wind ripples, expanding rings where
  fish surface and where the spout lands, sun glint.
- **Koi:** 8–14 fish in ten colour varieties, simulated individually (wandering, schooling,
  avoiding the bank), swimming with a travelling body wave. Stand still at the bank and they come
  over.
- **Planting:** up to 330 pines, small flowering trees, grass, ferns, shrubs, broad-leaf plants,
  hydrangeas, wildflowers, water lilies and reeds, all moving in one shared wind field.
- **Atmosphere:** drifting mist, shafts of light through the trunks, floating motes, birds
  crossing above the canopy, filmic tone mapping, bloom on the lanterns, depth of field in the tour.
- **Cameras:** first-person walk with collision, head bob and footsteps; a seven-shot guided tour
  (its first two shots are the opening sequence); a free orbit. Transitions blend or dip to dark.
- **Sound:** wind that follows the visible gusts, the spout positioned at the pond, birdsong placed
  in the trees around you, footsteps that change on grass, gravel, stone, bridge and veranda, koi
  surfacing, a wind chime, creaking timber. Four volume sliders and mute. Sound starts only after
  you press **Enter experience**.
- **Rain mode:** switch between the morning and a rainy day at any time; the change takes about
  five seconds and leaves the camera where it is. Overcast light and thicker mist, wind-slanted
  rain in three intensities, wet timber, tiles, stone and leaves, puddles on the paths, drops on
  the window glass, runoff from the eaves and the trees, raindrop rings and splashes on the pond,
  occasional distant lightning with delayed thunder. Rain sound is layered and positional (open
  garden, pond, bridge, cabin roof, under the veranda) with its own volume slider; thunder and
  lightning can each be switched off. Lightning starts off when the system asks for reduced motion.
- **Six points of interest** with a short note each: pond, bridge, veranda, spout, hydrangeas, pines.

## Stack

React 19, TypeScript, Vite 8, three.js 0.187 through @react-three/fiber and drei,
@react-three/postprocessing, Zustand, Web Audio API, Vitest. See `ARCHITECTURE.md` for structure

## Quality levels and performance

The starting level is chosen from the device (GPU name, touch, memory, cores). On **Auto** the
frame rate is measured continuously: below 30 fps the render resolution is lowered in steps to
60%, and if that is not enough the level steps down. Resolution is restored when there is
headroom. The level can be fixed by hand in the Graphics panel.

| Level | Pixel ratio cap | Shadows | Reflection | Post-processing | Grass tufts | Pines | Koi |
|---|---|---|---|---|---|---|---|
| High | 1.75 | 4096 | 1024 | AO, bloom, depth of field, SMAA | 120,000 | 330 | 14 |
| Medium | 1.25 | 2048 | 512 | bloom, SMAA | 52,000 | 220 | 11 |
| Low | 1.0 | 1024 | sky only | none | 20,000 | 120 | 8 |

### Measured

Test machine: laptop with integrated Intel Arc graphics (22 threads, 32 GB), Chrome, 1440×709
window at device pixel ratio 2 (1800×886 rendered on Medium).

| What | Result |
|---|---|
| Medium, walk view at the entrance | 34–42 fps, measured while another application was using about 94% of the GPU. Auto lowered resolution to 0.85× during this run |
| Scene size per frame, summed over the main, shadow and reflection passes | Low: 191 draw calls, 0.96 M triangles at 1440×709 · Medium: 337 draw calls, 2.9 M triangles at 1800×886 · High: 368 draw calls, 5.2 M triangles at 2520×1240 |
| Frame rate on High and Low | not measured (see below) |
| Time to "ready" on a warm cache (dev server) | about 3 s |
| Production build | 256 kB entry chunk (82 kB gzip), 1.44 MB scene chunk (469 kB gzip), 7.6 MB textures loaded progressively |

These numbers are a floor, not a clean benchmark: for most of the test session the GPU was shared
with another 3D application, and later the browser window was hidden, which makes Chrome throttle
rendering to about one frame per second. A clean frame-rate run per level on an idle machine is still owed. All three levels were built and rendered without errors.
Press `P` in the scene for a live readout of frame rate, level, resolution scale, draw calls and
triangles.

## Known limitations

- The brief refers to a reference image that was not in the project folder. The place is built
  from the written description, so layout and colours are an interpretation.
- Sound is synthesized. Wind, water and footsteps hold up well in this style; birdsong is
  recognisably synthetic on close listening.
- Vegetation is stylised rather than photographic: foliage is built from generated leaf cards.
- The ground among the distant trunks is plain under the mist; there is no undergrowth beyond the
  clearing.
- Ambient occlusion (High only) runs at full resolution, because the library's half-resolution
  path is incompatible with this three.js version. High is intended for discrete GPUs.
- Changing quality level rebuilds the scene, which causes a pause of a second or two.
- High draws about 5 M triangles per frame across its passes; it is meant for discrete GPUs and is never selected automatically for integrated ones.
- One-shot sounds rely on the browser to collect their finished audio nodes; this was not profiled over a very long visit.
- The browser console shows two deprecation warnings from the 3D libraries (`THREE.Clock`, `PCFSoftShadowMap`). They are harmless.
- No physical phone or Safari run was possible in the development environment.
