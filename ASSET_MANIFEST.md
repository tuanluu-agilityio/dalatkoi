# Asset manifest

Every asset in this project is either generated by the project's own code or comes from a source
with a clear, permissive licence. Nothing else is loaded at runtime: no CDN, no analytics, no
remote fonts.

## 1. Third-party textures (Poly Haven, CC0)

Downloaded by `scripts/fetch-textures.mjs` from the Poly Haven API and converted to 1K WebP.
Poly Haven publishes all of its assets under **CC0 1.0** (public domain dedication): free for any
use, no attribution required. Licence: https://polyhaven.com/license

Each set is three files in `public/textures/`: `<name>_diff.webp` (colour), `<name>_nor.webp`
(OpenGL normal map), `<name>_arm.webp` (ambient occlusion / roughness / metalness).

| Local name | Poly Haven asset | Page | Used for |
|---|---|---|---|
| `planks` | weathered_brown_planks | https://polyhaven.com/a/weathered_brown_planks | Cabin walls, bridge, trim |
| `deck` | wood_floor_deck | https://polyhaven.com/a/wood_floor_deck | Veranda floor, steps |
| `stonewall` | stacked_stone_wall | https://polyhaven.com/a/stacked_stone_wall | Cabin plinth, chimney |
| `bark` | pine_bark | https://polyhaven.com/a/pine_bark | Pine and small-tree trunks |
| `grass` | leafy_grass | https://polyhaven.com/a/leafy_grass | Lawn |
| `forest` | forest_floor | https://polyhaven.com/a/forest_floor | Ground under the pines |
| `gravel` | gravel_floor_02 | https://polyhaven.com/a/gravel_floor_02 | Paths |
| `rock` | mossy_rock | https://polyhaven.com/a/mossy_rock | Pond rocks, boulders |
| `pebbles` | ganges_river_pebbles | https://polyhaven.com/a/ganges_river_pebbles | Pond bed |

27 files, 7.6 MB in total. The app runs without them: `src/assets/textureManager.ts` substitutes
a generated texture for any file that is missing or fails to load.

## 4. Audio (original, synthesized at runtime)

There are **no audio files**. Every sound is produced in the browser with the Web Audio API from
generated noise and oscillators:

| Sound | Source |
|---|---|
| Wind in the pines, bamboo spout stream and burble | `src/audio/synth/beds.ts` |
| Birdsong (five invented song types), footsteps on grass / gravel / stone / bridge / veranda, koi surfacing, water drops, wind chime, timber creaks | `src/audio/synth/voices.ts` |
| Noise buffers and the reverb impulse | `src/audio/synth/noise.ts` |

No recording, sample or copyrighted composition is used. Audio starts only after the visitor
presses **Enter experience**.
